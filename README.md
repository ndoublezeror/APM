# 🎵 Audio Player

A modern desktop music player built with **C#** and **WinForms**. Audio Player lets you play local audio files, manage playlists, and display album artwork in a simple and lightweight interface.

> 🚧 This project is currently a work in progress.

---

## ✨ Features

- 🎶 Play local audio files
- ⏯️ Play, Pause, Next, and Previous controls
- 📂 Playlist management
- 🖼️ Album cover display
- 🎤 Audio title and artist information
- 💻 Lightweight WinForms application

---

## 🛠️ Built With

- C#
- .NET WinForms
- Windows Media Player COM Control (`AxWindowsMediaPlayer`)

## 🚀 Getting Started

### Requirements

- Windows 10 or Windows 11
- Visual Studio 2022 or newer
- .NET (matching the project's target framework)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/ADP.git
```

2. Open the solution in Visual Studio.

3. Build and run the project by pressing **F5**.

---

## 🎧 Usage

1. Launch the application.
2. Add one or more audio files.
3. Select a song from the playlist.
4. Click **Play** to start listening.
